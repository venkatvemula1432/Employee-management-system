# Employee Management System

A Full Stack Employee Management System built using:

## Technologies

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- MySQL
- Maven

### Frontend
- React.js
- React Router
- Bootstrap
- Axios
- React Toastify

## Features

- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Add Employee
- View Employees
- Update Employee
- Delete Employee
